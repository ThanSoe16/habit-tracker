unchanged. Their employee/tenant schema, monorepo paths, imports, and UI strings

adapt their principles to this repository and replace the earlier conflicting
examples. Follow the user's current request when it differs from project guidance.

See the [adoption review](docs/rules-adoption.md) for verified changes and remaining
gaps. Adding rules does not mean existing code or database policies already meet them.
